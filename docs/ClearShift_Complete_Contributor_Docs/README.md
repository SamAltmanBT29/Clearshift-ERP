# ClearShift Complete Contributor Documentation

This bundle contains all contributor-guidance documents created for the ClearShift V1 team workflow.

## Contents

- `ClearShift_Team_Contributor_Guide.pdf` — print-ready team manual.
- `ClearShift_Team_Contributor_Guide.md` — editable canonical guide.
- `ClearShift_AI_Prompt_Playbook.md` — prompts for issue analysis, planning, implementation, testing, debugging, review and PR preparation.
- `ClearShift_Contributor_Quick_Start.md` — short issue-to-merge checklist.
- `ClearShift_PR_Template.md` — pull request content template.
- `AI_PROMPT_REVIEW_CARD.md` — compact prompt safety/review checklist.
- `QA_VALIDATION_REPORT.md` — guide package validation notes.
- `.github/PULL_REQUEST_TEMPLATE.md` — proposed repository PR template.
- `.agents/rules/clearshift-core.md` — proposed Antigravity project rules.
- `.agents/skills/clearshift-issue-execution/SKILL.md` — proposed repeatable issue-execution skill.

## Use and adoption

The `.github/` and `.agents/` files are proposed additions. Review them against the live repository, current issue state, approved architecture, and team policy before copying them into the repository. This package does not itself modify the repository or create/update GitHub issues.

Use the live GitHub issue and approved ClearShift Project Plan/SDS documents as the source of truth. Do not create duplicate issues from older catalog snapshots. Do not expose credentials, secrets, real customer/employee data, or private production material to AI tools.
